What it is

Claude Code is Anthropic's agentic coding assistant that works directly in your codebase across terminal, IDE, web, mobile, Slack, and GitHub.

It reads, writes, and executes code, runs tasks across parallel subagents, maps and explains entire codebases, and opens pull requests end-to-end without a remote code index.
